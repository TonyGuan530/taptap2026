## 一、核心循环走查（玩法策划视角）

**核心行动**：60 秒内仅两个操作——①点击槽位建造/升级浇水设施（20/40💧）②点击村民晋升精英（30💧）。每局实际发生 4~6 次投资决策，密度合适。

**目标与挑战**：温度条是唯一生存压力源；水滴收入是唯一资源约束。五阶段升温曲线（1.8+0.035t → 3.5+0.09t）叠加两场酸雨（设施×0.6/村民×1.5 双向修正）构成挑战主体。

**反馈与回应清单**（逐行动核对，全部双向闭合）：

| 玩家行动/系统事件 | 即时反馈 |
| --- | --- |
| 建造设施 | 贴图水塔出现 + 洒水动画 + 温度应答 |
| 升级设施 | II 级标注 + 降温 2→5 跳变 |
| 晋升村民 | ★ 星标 + toast + 降温 +0.7 |
| 酸雨预警（前 3 秒） | 药丸横幅闪烁 + 倒计时文案（决策窗） |
| 酸雨开始 | 震屏 + 闪电白幕 + 紫雨 + ▼设施蒙暗 / ▲村民提亮 |
| 酸雨结束（v11 补全） | 天光渐亮 1.25s + ☀ toast（设施恢复/村民回落） |
| 阶段切换（×5） | 横幅命名 + 进度条段色 + 天空/岩浆/火山环境连续渐变（v9） |
| 胜利/失败 | 结算面板（歌谣点名村民/失败建议） |

**奖励回路对照**：预警 3 秒的"准备好了"=多巴胺（奖励期待）；撑过酸雨、雨停天光=内啡肽（解除感）；结算歌谣点名村民+★=血清素（成长与命名认同）。三通道齐备。

## 二、节奏与心流走查（五阶段压力曲线）

| 阶段 | 窗口 | 升温 | 体验设计 | 走查观察 |
| --- | --- | --- | --- | --- |
| 初火 | 0-12s | 1.8+0.035t | 学习窗，容错高 | C01/C02：首塔回本快，无挫败 |
| 干热风 | 12-25s | 2.2+0.045t | 第一次预警+酸雨1（15-23s） | C05/C06：首个决策点，村民 20s 到位形成完整选择 |
| 裂地脉动 | 25-38s | 2.7+0.055t | 酸雨间歇，攒钱升级 | C08 天光反馈后进入安稳攒钱段 |
| 岩浆涌潮 | 38-50s | 3.1+0.07t | 酸雨2（46-54s）+压力叠加 | S09/C09：注意力峰值 |
| 灭亡倒计时 | 50-60s | 3.5+0.09t | 红警终局 | C10/S10：横幅转红+天空血红+升温峰值 |

- **心流形状**：压力爬升与玩家能力成长（设施 2→5、村民 0.8→晋升 1.5）大体同频；摆烂 26 秒败=压迫感基线成立。
- **已知风险（如实记录）**：最优会玩局终局 heat=0（snowball 未关闭，督导已记录留真人数据）；30-45s 段若玩家早期建满，中间段操作密度偏低——建议盲测重点观察该窗口的实际决策次数。

## 三、数值体验走查（数值策划视角）

- 经济：基础收入 5💧/s，村民 +1（搬运 +1.5）；消耗：建造 20 / 升级 40 / 晋升 30（工程师 -5）。单局总投入约 110~150💧，投入产出即刻可见。
- **核心决策的机会成本切换**（v3 双向 modifier）：常态设施优（L2=5/s）；酸雨窗设施×0.6、村民×1.5——30💧 在窗内/窗外价值不同。遥测实测：会玩局酸雨前[设施 40💧/村民 0] → 预警+酸雨窗[设施 35~40💧/村民 30💧]，机器人代理完成策略迁移（Mechanical Gate PASS）。
- 酸雨总暴露：经典 16s / 风暴 12s（风暴强调切换次数而非堆 debuff）。
- 已知宽松点：会玩局终局 heat=0。曲线 v7 已收紧（后期 3.5+0.09t），snowball 判定留真人数据。

## 四、可读性与涌现（观察项①~⑤ 走查）

1. **多重标记下角色可读性**：职业专属贴图（v12：黄帽扳手/绿巾浇水壶/蓝披风向标/白巾背桶）后，职业即剪影；★/▲▼ 为叠加层。C06/S13 同屏检查：可辨。→盲测确认。
2. **血红 vs 酸雨紫辨识度**：v9 氛围渐进后期天空转血红，酸雨紫雨叠加其上——C10/S13 目检尚可区分。→盲测确认。
3. **环境亮度 vs 轮廓可读性**：v11 天光仅 40% 插值且 1.25 秒衰减，C08 未见轮廓丢失。
4. **双帧漂移**：v10 双帧为同源生成，目检比例一致。（v12 起职业贴图为静态单帧，双帧仅用于基础村民/菜单。）
5. **"酸雨结束了"感知**：v11 天光+☀ toast 双通道，C08 帧明确可读。

## 六、文案与叙事点

- 阶段命名链（初火→干热风→裂地脉动→岩浆涌潮→灭亡倒计时）自带叙事递进。
- 结算歌谣（"村民们的名字会被写进歌谣：阿岩★、小露"）= 最小但有效的情感收束。
- 失败文案给策略提示而非指责（v10 起）。
- 世界观（《最后的溪流》100℃→35℃ 生态恢复）深植于温度阶段与视听渐变，未额外堆文本——符合碎片化叙事。

## 七、结论与优先建议

**结论**：核心循环完整、反馈链双向闭合、五阶段节奏成立、模式辨识成立、职业身份可读——**达到"可进入真人验证"的完成度**。这与 ChatGPT 督导 v12~v14 连续备案结论一致（ITERATE，唯一 Gate=真人盲测）。

**优先建议**：
1. **真人盲测**（唯一 KEEP 通道）：按 reports/blind-test-kit.md 执行——≥2 人经典→经典 + ≥2 人经典→风暴，v14 基线，只说"撑过 60 秒"，各玩 2 局，结束后问"酸雨时为什么这么花水滴"；回收观察项①~⑤+横幅两点+双帧漂移。
2. **盲测重点数据**：30-45s 决策密度窗口、酸雨窗内外的投入迁移、职业辨识速度。
3. **不做清单**（督导既有裁定）：加阶段/天气/职业/建筑/提示文字、追调 snowball 数值、扩 4-6 帧动画。
