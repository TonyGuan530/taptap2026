## demo-03 给岩浆降温的小人国度

- 一句话玩法：通过强化/自动化更强的浇水/降温，来达成维持温度的目的，中途随进度解锁（涌现）随机 NPC 小人
- 操作方式：放置浇水/降温设施 → 温度实时变化条 → 攒资源升级设施 → 随进度随机解锁 NPC 帮手
- 验收标准（GPT 评审用）：
  - [ ] 温度持续上升的压迫感（不作为会输），设施能实际拉低温度

  - [ ] 游戏中后段解锁至少 1 个 NPC 小人并有可见帮助
  - [ ] 撑过 60 秒 = 胜利
- Miro 2026-10-03 详细设计补充（看板长文《最后的溪流》，供后续迭代参考）：
  - 世界温度阶段：100℃ 熔岩覆盖世界 → 80℃ 世界变化 → 60℃ 出现少量植物 → 50℃ 云层形成 → 35℃ 河流扩张（目标）

  - 建筑系统：山洞外平台（初始基地）、溪流水库（储水）、气象台（人工降雨）、蒸汽工坊（蒸汽转动力）

  - 道具：主动（人工降雨弹/冰霜/超级水桶）+ 战略（蒸汽发动机/云层催化器）
  - 涌现机制：居民 AI 自主行为（打水/浇灌/运资源/建造）、环境连锁（岩浆降温→矿石→探索资源）、生态正反馈（降水→资源→更多降水）
