## demo-01 灵感菇侦探

- 一句话玩法：你是一个能听到物品说话的侦探，从犯罪现场物品的只言片语中还原案件的"真相"
- 补充方向：叙事涌现 & 线索涌现（Miro 侧标签）
- 操作方式：鼠标点击场景中的物品 → 物品说出一条"证词" → 收集线索 → 指认真相
- 验收标准（GPT 评审用）：
  - [ ] 场景内至少 5 个可点击物品，每个点击后有独立证词文本
  - [ ] 线索面板实时收集证词，收集齐后"指认真相"按钮可用
  - [ ] 指认有对/错反馈，正确时展示案件还原小结局
  - [ ] 一局 2-3 分钟内可完成
- 状态：待开发

## demo-02 Unit-Testing：物性变换谜题

- 一句话玩法：通过改变物品的单位/词条，改变物体的物理属性，以此解谜
- 补充方向：塞尔达式箱庭谜题（Miro 侧关联笔记）
- 操作方式：点击物品 → 给它换个"单位/词条"（如 把"水"标成"石头"）→ 物理行为随之改变 → 达成通关条件
- 验收标准（GPT 评审用）：
  - [ ] 至少 3 种可切换词条，每种对应 visibly 不同的物理行为（如 重力/固液态/弹性）
  - [ ] 至少 2 个设计好的谜题关卡，改错词条会失败并提示
  - [ ] 改词条后物品运动由物理引擎驱动，肉眼可见变化
- 状态：待开发

## demo-03 给岩浆降温的小人国度

- 一句话玩法：通过强化/自动化更强的浇水/降温，来达成维持温度的目的，中途随进度解锁（涌现）随机 NPC 小人
- 操作方式：放置浇水/降温设施 → 温度实时变化条 → 攒资源升级设施 → 随进度随机解锁 NPC 帮手
- 验收标准（GPT 评审用）：
  - [ ] 温度持续上升的压迫感（不作为会输），设施能实际拉低温度
  - [ ] 至少 2 级设施升级，资源随时间/效果产出
  - [ ] 游戏中后段解锁至少 1 个 NPC 小人并有可见帮助
  - [ ] 撑过 60 秒 = 胜利
- 状态：待开发

## demo-04 SOUP 2.0：DNA 融合逃生

- 一句话玩法：和外星生物的 DNA 融合改造自身，以逃离危险的异星
- 操作方式：遭遇外星生物 → 选择融合其 DNA 获得能力（如 跳跃/攀爬/发光）→ 用新能力通过地形障碍 → 逃脱
- 验收标准（GPT 评审用）：
  - [ ] 至少 3 种可融合的外星 DNA，各解锁一种移动能力
  - [ ] 有至少一段必须使用新能力才能通过的地形
  - [ ] 到达终点有逃脱结算画面
- 状态：待开发
