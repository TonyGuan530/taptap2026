# demo-04 3D 资产规格（接入加载器配套 · 2026-10-05）

> 接入方式：**PNG 放入 `game/assets/` → 发版**，零代码改动（加载器已实装并测试）。
> 格式：RGBA PNG，**背景透明**（加载器不做抠图）。
> 全部为 billboard（始终面向相机），无骨骼动画需求。

## 文件清单（5 张）
| 文件名 | 建议尺寸(px) | 内容 | 备注 |
| --- | --- | --- | --- |
| `player.png` | 64×96 | 小小宇航员（白+橙太空服，汤碗标志） | 奔跑姿势或直立 |
| `alien_glow.png` | 64×64 | 灯灯菌（黄色发光蘑菇） | |
| `alien_highjump.png` | 64×64 | 蹦蹦兽（紫色弹跳生物） | |
| `alien_break.png` | 64×64 | 恐龙兽（红橙壮实恐龙） | |
| `alien_double.png` | 64×64 | 双翼虫（蓝色带翼生物） | |

## 生成提示词参考（ChatGPT/图像模型）
统一风格：卡通厚描边、纯色绿幕背景（#00ff00，后期抠图）或直接透明背景、
角色居中占画面 70%、无阴影无地面。

## 技术参数
- 接入后自动 billboard（始终面向相机），像素尺寸 player 0.004 / alien 0.006
- 灰盒自动隐藏（无叠加残留）
- 加载器：root.gd `_load_player_asset` / `_try_alien_asset`（回退链兼容 headless）
- 验证：用例 29/30 三段断言（生成→加载→替换→清理→还原）

## 不需要
- 骨骼/动画文件（billboard 静态即可）
- 场景/地形资产（灰盒几何已验证）
- 音频（程序化音效已实装）
