# 被试指引卡（打印或投屏用 · 观察者请勿额外解释）

## 你会玩到什么
一个第三人称 3D 平台游戏：你流落到陌生星球，需要**想办法逃离**。
路上会遇到奇怪的外星生物——靠近它们看看会发生什么。

## 操作
| 按键 | 作用 |
| --- | --- |
| W A S D / 方向键 | 移动 |
| 空格 | 跳 |
| E | 互动 |
| R | 重来 |
| Shift+R | 全部重来 |

（进入特定模式后还有更多按键，游戏内会提示）

## 请你做
1. 玩之前，告诉观察者你的编号（P1~P5 中的一个，游戏内可按 G 切换确认）
2. 尽情探索，卡住了就多试试——**试不出来也没关系，说出你当时的想法最重要**
3. 玩的过程中请「出声思考」：你想做什么、你猜什么会有用，直接说出来
4. 结束后按 T，把你的游戏记录导出（文件名里有你的编号）

## 观察者记录（被试勿读）
- 首次尝试与放弃的时间点 · 自发假设原话 · 相机/落点问题次数
- 提醒被试按 G（编号）与 T（导出）的时机：开始时 / 结束时
