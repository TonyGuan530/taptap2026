# demo-05 v2 改造设计文档：从 60 秒短局到饥荒/环世界式生存

> 用户指令（2026-10-04）：「我想改成像饥荒和环世界一样的游戏，现在的不行。」本文档用 game-designer 技能方法论（KES/核心循环/3C/数值五模块）过一遍现有游戏，给出形态级改造设计。**用户指令优先于督导 V8 冻结约束**——形态推翻，旧短局版（v1-v22）在 git 历史 与 Pages 构建永久存档。

## 一、KES 审视现状（60 秒短局版）

- **K（核心点）**：灾前布防 + 灾后撤离的卡牌式风险博弈
- **E（扩展）**：五幕灾难链 / 四路线 / 三状态 / 应急四卡 / 文风四体
- **S（标准）**：余量计分 / 240 局支配性模拟 / 行为学 Gate

**用户判死的原因（用核心循环三要素拆）**：
1. **核心行动错位**：玩家最主要的行为是「点卡牌」，不是「生存」——没有移动、没有探索、没有亲手采集与建造，缺失饥荒式的「我亲手活下来」的具身感
2. **时间结构错位**：60 秒一局 + 固定五幕脚本 = 谜题；饥荒/环世界的魅力是「时间在流逝，世界不等你」的持续压力与「活过今天」的短期目标
3. **反馈稀薄**：五幕链一次性播放完毕即结算，缺乏采集/建造/进食的即时微反馈循环
4. **世界扁平**：5 个地块卡片是按钮不是空间——没有可探索的地图、没有距离成本、没有「营地感」

## 三、v2 设计（KES）

- **K（核心点）**：「带着族群在火山灰末日里活过每一天」——实时生存压力 × 火山灰推进的空间压迫，玩家亲手移动、采集、建造
- **E（扩展路线）**：v1 核心循环（移动/采集/吃喝/营火/昼夜）→ v2 巢穴与睡觉 → v3 火山灰夜潮推进与事件横幅 → v4 建造菜单扩容与烹饪 → v5 族群成员（环世界式多恐龙）
- **S（标准）**：60 FPS 稳定；存活天数+事件链结算；头部less 模拟判据（存活 N 天 / 灭亡对照）；旧四用例判据废弃（形态变更）

## 四、v1 核心循环（本轮交付）

```
昼夜循环(90s/天) → 白天：移动采集(浆果+食/水潭+水/枯枝+材) → 夜晚：火山灰推进+视野收缩 → 回营火/巢穴安全区 → 天数+1
三状态：饥饿/口渴 持续下降 → 吃浆果/喝水恢复 → 归零扣生命 → 生命归零=灭亡结算
建造：营火（枝条×5，夜间照明+缓慢回血光环）
```

## 六、测试判据（实时模拟，真实时间）

1. 存活判据：模拟运行 100 秒（≈1 天）且三状态未全灭 → PASS
2. 灭亡判据：断供状态（不可采集）运行至生命归零 → 灭亡结算 → PASS
3. 建造判据：集齐 5 枝条建营火 → 夜晚照明状态生效 → PASS
4. 回归判据：旧 4 用例废弃（形态变更），新建 3-4 条实时判据
