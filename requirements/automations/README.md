# 自动化任务创建包 · 使用说明

6 个 demo 各有一个专属自动化对话（每 30 分钟一轮，错峰 5 分钟：:00/:05/:10/:15/:20/:55）。

## 创建步骤（每个 demo 约 1 分钟）

1. 开一个新的 ZCode 聊天
2. 打开本目录下对应的 .md 文件，全选复制「——」以下的全部内容
3. 粘贴到新聊天发送——它会自我介绍为该 demo 的专属对话，并创建自己的定时任务
4. 创建成功后，把定时任务返回的信息确认一下（任务名/周期）

## 停滞即转向（扩展阶梯）

某 demo 连续 2 轮没有实质进展时，按阶梯转向，选第一合适的：
1. **扩展玩法**：给现有机制加新组合（如 demo-02 加跳跃输入系统实现空中切词条）
2. **补充关卡**：用现有机制加 1-2 个关卡（每游戏目标 3-4 关）
3. **迭代美术**：视觉/音效/反馈打磨（粒子、转场、UI 润色）
4. **转 3D 尝试**：仅玩法确实适合 3D 时（如 demo-04 横版改 3D 探索），先在对话说明可行性再动手

转向时在报告注明「停滞转向：demo-XX → 阶梯项」。

## 注意

- **测试验证一律走 GitHub Pages 公网链接或 itch 页面，不要用 localhost 本地前端**（本地站只做 Review 留言板）
- **停滞兜底**（用户指令）：某 demo 轮次无可执行项或连续两轮无实质变化时，按序挑一项做——①扩展玩法（评审约束内）②补充关卡 ③迭代美术 ④转 3D 尝试（仅当合适且 2D 已到天花板，先征求 ChatGPT 评审意见）；不许空转，所选方向写进报告与评审汇报

- 一个 ZCode 会话只能拥有一个定时任务——所以必须开 5 个新聊天分别创建
- 任务错峰 5 分钟，避免 Godot 导出锁冲突；若上一任务的导出仍在跑，流水线会自动等待/跳过
- 创建完成后在对应 demo-0X.md 里记下新任务返回的会话 URL（ChatGPT 专属对话同理）
- Windows 轻量流水线（pipeline-lite.bat，5 分钟）独立运行，负责 itch 健康自愈/Miro 同步，与此 6 任务互补
