# demo-04 3D 真人盲测协议（Phase D 准备 · 2026-10-05）

## 构建与入口
- 版本：demo-04-3d-v11（或更新）；Web 试玩：https://tonyguan530.github.io/taptap2026/builds/demo-04-3d-v11/index.html
- 操作：WASD/方向键移动 · Space 跳（二段需 DNA）· E 融合 · R 重开本关 · Shift+R 完整再跑 · K 实验房 / 1~5 选关（实验房内直达任意关）/ B 返回 / G 切被试编号 / T 导出遥测
- 遥测：G 键设定被试编号（P1~P5）后，T 键双写导出（浏览器下载 + IndexedDB）。**每名被试开始前务必按 G 切换到自己的编号。**

## 样本与流程（沿用 2D 协议骨架）
- 两样本：campaign-first ≥3 人（直接开玩）；lab-first 1~2 人（先进实验房把玩全 DNA，再打战役）
- 零提示规则：只解释「移动、跳跃、找到外星生物按 E 融合」；**不透露**组合配方、上层栈道、碎岩解法、弹跳板位置
- 首玩分离：每名被试独立会话；观察者全程不干预，只记录
- 每人 ≤25 分钟或自然通关

## 观察项（3D 版）
### 沿用 2D
- [ ] 首次遇墙/沟/暗区/裂纹墙的反应与用时（认知延迟）
- [ ] DNA 融合顺序与对提示文本的理解
- [ ] 组合发现时机（超级弹跳/夜翼）与主动配对假设的原话
- [ ] 发现捷径/机制后是否回头复用
### 3D 新增（指南 §D 指定）
- [ ] **相机迷路**：丢失角色/方向感频次（第三人称跟随）
- [ ] **落点难辨**：跳跃后找不着落台的次数
- [ ] **侧带机制发现率**：西侧空中栈道（L3/L5）与弹跳板（L1 z 侧带）被自发发现的观察
- [ ] 暗区实体（黑暗体积）是否被理解为「危险区域」
- [ ] 掉坑恢复感知：是否注意到「DNA/碎片保留、计时继续」
- [ ] 键盘学习曲线（相对 2D 是否多出负担）
