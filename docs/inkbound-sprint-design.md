# 墨迹漂流 · INKBOUND

## 一句话

在一本被墨水洪流冲散的绘本里，画出真实形状，给它附上野外捡到的词条，用自己想出的工具找回画页。

## 竞争策略

蘑菇侦探已有成熟房间、角色、调查界面与引导。本次集中一个可完整游玩的精致关卡，突出玩家亲手创造工具的过程。首屏清楚、操作立刻反馈、结尾可分享；不以地图数量作为完成度。

## 美术与角色

低多边形纸雕庭院：奶油纸岩、青蓝墨河、珊瑚红植物与点缀、深靛墨轮廓。物体保持清晰的平涂大色块，减少密集文字牌。旧箱体墙保留必要碰撞，视觉改为折纸断壁、木桩和植物。主角是戴宽帽、红围巾、背墨瓶的绘画学徒；小体型、大帽沿、白纸面孔与两点墨眼。实装为可读的程序化 3D 角色，概念图另作为美术目标及展示页资产。

## 5 分钟流程

1. **落笔（0–60 秒）**：看见钥匙与门，捡到第一枚词条，打开画纸。画一条有长度的钩线并附【黏附】，够到钥匙；【磁性】提供另一种抓取办法。线太短时指出“还差距离”，保留作品，不要求重画。
2. **过河（60–180 秒）**：同一个河岸目标有两条路线。闭合轮廓附【漂浮】形成承载面，或开放线附【弹性】连接对岸木桩。图形的长度、覆盖范围和接触实际参与判定。墨泉补给鼓励试错。
3. **带回画页（180–300 秒）**：藤根与机关两条通道。开放线附【锋利】切藤；重物、工具或防护面提供已有规则支持的替代路线。抵达庭院取得画页，展示实际使用的解法与完成时间。

## 手感验收

- 画纸打开后笔迹即时跟随，笔尖可见；松开后作品持续显示。
- 开放线 / 闭合面清楚区分，给出实测长度或面积及预计墨耗。
- 词条选择带颜色、说明和当前选中状态；装配后立即回到可操作世界。
- 同一个作品可换词条、旋转、回收；失败不删除已画作品。
- 接触有效目标有颜色、音效与短提示；成功显示机关变化。
- 目标以一句话呈现，说明按需出现在画纸和提示区。
- 必须通过普通浏览器输入完成流程；脚本按钮不能代替试玩。
- 使用前在世界显示真实路径或轮廓落点。初次落笔区无敌人追击，战斗安排在对岸；墨泉同时修补纸张，支持尝试另一条路线。
