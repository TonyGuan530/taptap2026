# 墨迹漂流 V9 验收

2026-10-06，Godot 4.7.2 Steam，Windows 无头原生检查及隔离的无头 Edge WebGL 浏览器。

## 构建

`tools/export-inkbound.ps1` 的最终执行：资源导入、原生场景启动、Web 导出均 exit 0。三个最终 stderr 日志均为空；index.html、index.js、index.wasm、index.pck 存在。导出脚本在 finally 恢复调用前的共享项目配置。

## 真实输入流程

`node tools/verify-inkbound-web.mjs --record` 与 `node tools/verify-inkbound-web.mjs --float --record` 均通过。测试只通过普通键盘与鼠标事件操作；`?qa=1` 仅读取状态，不写游戏状态或传送玩家。

两条路线均完成：点击角色介绍 → 走到野外词条并拾取六种性质 → 短黏性线因距离不足失败，作品仍保留 → 重画长线取回钥匙并开门。

- 路线 A：亲手画开放线并装配弹性，实际连接对岸并拉过河；换锋利词条，线条触碰并切断藤根；走入庭院、取得画页，结算记录弹性长绳与切藤。
- 路线 B：亲手画闭合轮廓并装配漂浮，生成带碰撞的承载面；普通行走过河；磁性线触发实体安全机关，走入庭院取得画页，结算记录漂浮承重与磁吸停炮。

两条路线均 won=true，控制台错误 0。通关自动操作用时约 41–42 秒；探索型首次游玩设计目标约 5 分钟，并非实测用户平均时长。

额外输入回归确认：同一幅闭合画先换沉重、再换漂浮，顶点保持一致，无需重画；R 旋转封闭造物，随后继续用该轮廓完成过河与通关。

## 展示与录像

`node tools/verify-inkbound-entry.mjs` 检查四张页面图片、两段 MP4 元数据、390px 无水平溢出、启动按钮及嵌入游戏到达 V9 角色介绍，错误和 HTTP 失败均 0。

两段录像来自实际游戏 canvas 和游戏音频：弹性路线 62.218 秒，漂浮路线 63.720 秒，960×540，各有 1 条音轨。发布格式为 H.264/AAC MP4。预览截图为实机；封面与角色大图明确标为设计图。

## 发布方式与边界

V8 恐龙与画家作为固定历史入口先发布，线上启动检查两款均 version=8、started=true、错误 0。V9 通过独立发布 checkout 从当前远端 main 加入，仅替换画家 3D 卡片、新增专属入口与依赖文件，保留其他作品与 V8 固定入口。线上验收结果将在完成 Pages 部署后补充。

Miro 已新增独立分区、五张策划卡、场景概念图与角色图，并回读确认。

试玩要求键鼠。V9 是一段精修关卡，继承原有流式地形，不宣称已完成无限开放世界的内容打磨或玩家群体手感测试。

复现浏览器检查前安装工具依赖：`npm install --prefix .codex-tmp/lowpoly-tools playwright-core`。本地静态服务使用 `PORT=8788 node server/server.js`。通过 `INKBOUND_BASE` 和 `INKBOUND_URL` 可检查发布地址。
