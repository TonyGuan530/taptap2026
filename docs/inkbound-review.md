# Inkbound V9 审查记录

2026-10-06。审查对象为独立的 V9 继承扩展，保留 V8 游戏规则与历史入口。

独立审查由 `inkbound_review` 完成，检查脚本、绘画输入、碰撞与显示的一致性，并用 Playwright 原生鼠标拖动生成 41 个绘画顶点、Enter 装配、Tab 再次打开画纸。

发现的问题及处理：

- QA 投影早于最终相机位置：改为先更新相机，再发布只读状态。
- 角色介绍的 TextureRect 设置顺序导致布局警告：先设置 expand_mode，再赋贴图和尺寸。
- 部分不可见墙仍有碰撞：关键内墙、门栏和钥匙围栏增加连续可见几何。
- 展示页缺实机图与有效录像：两条路线重新录制，确认 WebM 文件头、游戏音轨，转为 H.264/AAC MP4。

主代理随后完成两条完整普通输入路线、页面资源、录像元数据、390px 布局和嵌入游戏检查。两条路线均到达结算，浏览器错误为 0。最终验收见 `inkbound-validation.md`。

全程使用隔离的无头浏览器，无原生窗口或桌面录屏。概念图与实机图分别标注。手机仅验收展示页布局，试玩要求键鼠。
