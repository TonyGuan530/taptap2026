# L12 · 限速检测 · 规则契约（机制关卡 r3d-3）

## 概述
新增第十二关：**限速检测线**——首个"驾驶技术门"。两道检测线要求过线车速达标，
跨线时车速低于线速 → 检测不通过判负（settle "speed"）。与 L11（车库决策门：尺寸）
互补：本关考**动量管理**——爬坡掉速后必须全力冲刺补速，松油门/刹车即失败。
视觉用基座 pressure_plate（路面检测板，压平横贯路宽）+ gate_frame 门架；纯标记
无碰撞——判定是规则层跨线测速，非物理障碍。

## 判定模型（lane_core）
- setup 预计算 `speed_gates_px = {gx·10, vmin·10}`。
- step 记录 `prev_x`（积分前质心 x）；积分后逐线检查：`prev_x < gx ≤ car_pos.x`
  （**前向跨线事件**，非窗口式）且 `vel.length() < vmin` → settle "speed"，
  记录 last_speed_vmin/last_speed_val（结算文案展示"过线车速 x，要求 y"）。
- 仅前向跨线判定：倒车回退再前进会再次跨线再判（自然语义）；跨线时刻的瞬时速度
  为判定值（悬空过线也判——空中无驱动，速度只降不升）。
- 刚体路径同规则：根脚本 `_physics_process_rigid` 以 `_rigid_prev_z` 做同样跨线测速
  （rigid z 轴负向前进）。
- `speed_gates` 字段门控：无该字段的关卡行为与旧版位级一致（lane 锁步锁定）。

- 地形 seed：`900 + 11×77 = 1747`
- **地形标定教训**：首版 a1=14/w1=220（坡度 21.8°）在 55m/s 下坡段把车发射上天
  （滞空 4.1s、落地仅 38m/s）——线 2 物理不可达；放柔到 8/400（12.6°）后全油门
  滞空 2.0s、双线可达。限速线的 vmin 标定必须与地形弹道耦合考虑。
- 车身敏感性：宽扁（drag 1.35）极速 ~50 < 线 2 要求 55——**宽扁车身在本关不可通关**
  （低净空优势在 L11、动量劣势在 L12，跨关卡车身取舍成立）。

## 验收标准（l12viable 6/0）
1. 4×r14 对全油门双线通过完赛（9.6s）
2. 3×r16 三角全油门双线通过完赛（9.5s）
3. 230–252m 刹车窗口后滑行 → 线 1 判负（41.1 < 45，线速记录正确）
4. 415m 起滑行 → 线 2 判负（37.8 < 55，线速要求记录正确）
5. 失败用例的滑行必须贴近下一道线——远离线的滑行会在坡上停摆振荡、永不跨线
   （guard 超时无结算），测试设计须避免
