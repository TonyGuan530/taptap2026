# L5 · 连续陡坡 · 规则契约（机制关卡 DRAFT-1）

## 概述
新增第五关：连续四段陡峭爬坡+陡降，考验驱动轮抓地与配重。新增机制：**坡度超过悬挂行程
的陡坡面**——车速不足则卡坡回滑（2D lane_core 已有此物理：陡坡面驱动沿切向、重力竖直向
下，坡度大时切向分量不足以克服重力分量→回滑）。

## 关卡参数
| 参数 | 值 | 说明 |
|---|---|---|
| target_m | 600 | 四关中中等长度 |
| min_wheels | 2 | |
| rear_min | 2 | 后半段至少 2 轮：爬坡需要后轮抓地 |
| max_r | 0（不限） | 不加尺寸限制——纯驾驶测试 |
| budget | 0（不限） | |
| a1/w1 | 12.0 / 200 | 第一段陡坡：6° 坡度 |
| a2/w2 | 18.0 / 140 | 第二段更陡：≈7.4° |
| a3/w3 | 24.0 / 600 | 长波基线：整体爬升趋势 |

- 地形 seed：`900 + 4×77 = 1208`
- 陡坡机制：a1=12px(1.2m)/w1=200px(20m) → 最大坡度 arctan(2π×12/200) ≈ 20.6°。
  2D lane_core 陡坡驱动力沿切向，重力竖直向下——坡度 > atan(DRIVE_ACC/GRAVITY) = atan(85/90) ≈ 43°
  时无法纯靠驱动爬升。20.6° < 43° ✓ 可爬但需足够速度动能。

## 验收标准
1. 标准双大轮布局（0.15/0.85 r18）在 60s 内完赛
2. 短轴距小轮布局在 60s 内完赛（可能翻滚但过关）
3. 前二轮布局（无后轮）拒发（rear_min=2）
4. 桥梁路径与刚体路径均可达 400m+（刚体允许在坡顶跳起）
