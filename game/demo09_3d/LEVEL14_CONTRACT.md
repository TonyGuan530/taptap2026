# L14 · 加速带 · 规则契约（机制关卡 r3d-3）

## 概述
新增第十四关：**加速带**——首个**增益机制**（此前全部机制都是判负/障碍向）。
跨过路面加速板瞬间沿当前行驶方向提速 dv（SPEED_MAX 封顶），无状态、无冷却。
本关与限速线组合：两道检测线车速（72/80 m/s）**超过极速 ~65**——只有贴线
（3m 前）吃下加速板（+15/+20）才过得了线。

## 判定模型（lane_core）
- setup 预计算 `boost_px = {gx·10, dv·10}`。
- step 积分后：前向跨带（prev_x < gx ≤ car_pos.x）→
  `vel = vel.normalized() · min(|vel| + dv, SPEED_MAX)`。
- 刚体路径同规则（根脚本 `_physics_process_rigid`，米制封顶 90 m/s）。
- 视觉：与限速线/检查点同族（build_line_markers：gate_frame + pressure_plate）。
- `boosts` 字段门控：无该字段的关卡行为与旧版位级一致（lane 锁步锁定）。

## 核心设计发现：阻力吃加速（本关标定的关键）
- 极速 ~65 m/s 处的二次风阻 ≈ 110 m/s² 减速度——**提前加速会在几十米内被吃光**：
  探针/扫参实测 pad@290 或 pad@200（dv 10~12）对沟壑弹道落点几乎零影响
  （14m 沟带不带都过、16m+ 带不带都坠）。
- 加速带唯一可靠用法：**贴着消费点**——线前 3m：65.6+15=80.6，3m 内衰减 ~4-5
  → 过线 ~75-76 ≥ 72 ✓ 余量充足。距线 15m 以上即不可靠。
- （副产品教训：跳跃弹道由"悬挂分离点+分离速度+3m 甲板深度判定"共同决定，
  解析模型无法可靠预测，一律扫参实证——L10/L14 两次验证此纪律。）

## 验收标准（l14viable 6/0）
1. 跨带提速生效（Δ=15.0 m/s 精确）
2. 无带对照（桩模型去掉 boosts）线 1 判负（64.0 < 72）——加速板是通关必需
3. 4×r14 对吃带完赛（8.2s）
4. 3×r16 三角吃带完赛（8.2s）
5. 4×r16 超预算拒（3217>3200）
