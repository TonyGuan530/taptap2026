# L11 · 限高架 · 规则契约（机制关卡 r3d-3）

## 概述
新增第十一关：**限高架**——首个"尺寸约束门"机制关。道路 x=gx 处设横杆，净空
clear 米；**名义车高**超过净空 → 撞杆判负（settle "gate"）。
与预算（Σπr² 面积约束）互补：轮径直接决定名义车高，限高架 = **逐轮径硬上限**。
横杆以上视为封闭（不可跳越）。

## 判定模型（lane_core）
- **名义车高（技术检查口径）**：`beam_y + SUSP_LEN + max_r + hh`（像素），
  launch() 一次计算。与行驶姿态/悬挂压缩**无关**。
- step 中：质心进入杆窗口（|car_x − gx·10| ≤ 半长）且 `clear·10 < nominal_top_px`
  → settle "gate"（先于终点检查）。
- **为什么用名义口径**：实测实时车顶随驱动扭矩抬头摆动（4×r14 巡航 6.05–6.12m，
  名义 6.0m）——轮径档位差只有 0.2m，实时口径的分界会被姿态噪声吃掉（两轮调参
  均在 3cm 级边缘翻车）；名义口径下 1px 级分界完全确定，且语义等同真实赛车
  的过杆技术检查。刚体路径则由横杆真实碰撞盒物理撞杆（无规则判定）。
- `gates` 字段门控：无 gates 的关卡 gate_px 空、行为与旧版位级一致（lane 锁步锁定）。

## 车高几何（判定依据，标准车身 body1：beam_y=13, hh=17）
名义车高 = 13 + 20 + r + 17 = **r + 50px**。净空 6.7m（67px）→
**r ≤ 16 过杆（66px）、r17 触杆通过（=67px）、r ≥ 18 撞杆（68px）**。
（宽扁车身 r+46：r≤20 过；高窄车身 r+56：r≤10 过——车身选择真实影响过杆能力。）

## 验收标准（l11viable 7/0）
1. 4×r14 对过杆完赛（7.6s，名义 64px<67px）
2. 3×r16 三角过杆完赛（7.6s，名义 66px≤67px）
3. r12+2×r18 三轮撞杆判负（settle "gate"，净空记录 6.70m）——预算内但杆杀
4. 4×r16 超预算拒（3217>2600）；≥2 布局完赛 + 撞杆路径可发生
