# L10 · 断崖沟壑 · 规则契约（机制关卡 r3d-3）

## 概述
新增第十关：**道路真开洞**——首个"沟壑"机制关。道路可视网格与碰撞形状在 `gaps` 区间
同步剔除（同源开洞，段界 2m 网格对齐）；lane_core 中沟壑区间内的轮子失去支撑、
角点钳制跳过（桥接=腾空），坠落由**沟沿甲板深度**判定（r3d-3 行为扩展，仅限含
`gaps` 字段的关卡；无沟关卡位级不变，lane 锁步 16/0 锁定）。

## 物理模型（三规则，缺一不可）
1. **轮支撑抑制**：轮心投影 ∈ [g0,g1] → 无弹簧力（悬空）。
2. **桥接钳制跳过**：质心 ∈ [g0-半长, g1+半长] → 车身四角防穿地钳制整体跳过。
   否则沟下连续的解析地面会把坠沟车"捞"上远侧路面（传送救援）。
3. **坠沟判定**：桥接窗口内质心跌破**沟沿甲板**（min(ground_y(g0), ground_y(g1))）3m
   → settle "fall"（判负，优先级同翻车：先于终点检查）。
   甲板必须取沟沿而非沟下解析地面（后者随正弦起伏不可作基准）。
   **窗口必须与规则 2 完全一致**——否则存在"既不判坠也不钳制"的坠落漏区。

- **核心设计发现：平地沟不可跨越**。抛物线落点必低于起跳水平面（无 vy 时），
  平地沟的对岸崖壁无法到达——沟**必须**由跳台 crest 起跳（vy>0 + 6m 高度预算）飞越。
  扫参矩阵（h∈{6,8,10}×len∈{8,10,12,14}×w∈{40,48}）显示 h=8/10 全灭：爬升吃掉的动能
  超过高度预算收益；h=6/w=48 时 len≤10 可飞越、12 即坠沟——失败边界紧贴可飞越域，
  速度即生命的关卡机制成立。
- 跨沟速度窗口：全速（55-58m/s）进台 crest 后约 43-48m/s，飞行 0.45s+6m 预算覆盖 10-12m。

## 验收标准（l10viable 8/0）
1. 4×r14 对完赛（10.3s）
2. r12前+r18后驱完赛（10.0s）
3. 低速注入坠沟 → settle "fall" 0.4s 触发（失败路径可发生）
4. grid_gaps 网格对齐（306-316/474-486）；开洞索引差=66（11 quad×6，同源剔除）
5. 4×r16 预算拒；≥2 布局完赛

## 实现
- garage_model：LEVELS 第十条 + `grid_gaps()` 静态助手（2m 网格对齐，lane/road 共用真源）
- lane_core：`gap_px` 预计算 + 轮支撑抑制 + 桥接钳制跳过 + 甲板深度坠沟（详见上模型）
- road_builder：`build(…, gaps_m=[])` 沟内 quad 剔除（可视+碰撞同源）+ 装饰跳过（rng 取数序不变）
- demo09_3d.gd：传 gaps；刚体路径坠落击杀（低于路面 20m 判 fall）；"坠沟"结算文案双路径
- 版本：r3d-3 不变（行为扩展由 `gaps` 字段门控，无沟关卡与旧版位级一致）
