# L7 · 悬挂极限 · 规则契约（机制关卡 r3d-3）

## 概述
新增第七关：高频搓板路（短波长高振幅连续颠簸），持续迫使悬挂在最大压缩附近振荡。
新增机制：**悬挂行程极限测试**——轮径选择直接决定是否频繁触底（托底 = comp ≥ MAX_COMP - 0.5）。
小轮在搓板路上会连续托底，大轮通过直径优势减少压缩比，预算约束限制"堆大轮"策略。

  MAX_COMP=1.4m，comp = a×sin(...) + 3.425 - r/10 - SUSP_LEN... 小轮（r16=1.6m）静态压缩
  就接近 MAX_COMP，搓板叠加后频繁触底 → 托底计数飙升。

## 验收标准
1. 双 r18 中线布局在 60s 内完赛（2×r18 Σ=2036≤3000 ✓）
2. 三 r14 三角布局在 60s 内完赛（3×r14 Σ=1847≤3000 ✓）
3. 4×r16 对布局在 60s 内完赛或翻车（4×r16 Σ=3217≤3000 超标 → 须用 r14 或更小）
4. budget 全路径校验正常

## 布局分析
- 双 r18 中线：r18=1.8m，静态压缩 = 90/(2×60) = 0.75m，悬挂余量 = 1.4−0.75 = 0.65m。
  搓板振幅 2.0m(0.2m) + 1.5m(0.15m) + 0.5m(0.05m) = 合计 0.4m 叠加波动 → 偶尔接近但
  不至于频繁触底 ✓
- 4×r16 对：r16=1.6m，四轮分摊 = 90/(4×60) = 0.375m 压缩，余量 = 1.4−0.375 = 1.025m ✓
  稳定但预算需 ≤3000：4×π×2.56 = 32.17×100 = 3217 > 3000 ✗ → 须降为 r14 或 r15
- 3×r14 三角：r14=1.4m，预算 3×π×1.96 = 1847 ✓，余量充足
