## 1 单位与坐标

- 换算 `10 px = 1 m`（`PX_PER_M=10.0`，:13）。世界系：X 侧向（右正）、Y 向上、前进 -Z；车模型局部机头 -Z。
- 旧二维核心先按 px 运行，再经下式映射到三维表现（阶段 A 受限轨迹桥梁）：

```text
progress_m = (old_x - START_X) / 10
world_position = Vector3(0, (BASE_GROUND_Y - old_y) / 10, -progress_m)
world_velocity = Vector3(0, -old_vy / 10, -old_vx / 10)
anchor_local = Vector3(lateral_m, -beam_y_px / 10, -(0.5 - xr) * body_len_px / 10)
ground_height(s) = (BASE_GROUND_Y - ground_y(START_X + 10 * s)) / 10
```

- 旧 `car_angle` 正=车头向下；Godot 节点旋转符号需另行映射，用水平/抬头/低头三基准姿态验证，不许照抄。

## 2 轮胎语义（契约核心）

- **一个 wheel 条目 = 一只实际物理轮胎，最多 4 只**（`WHEEL_MAX=4`，:33）。禁止自动镜像成左右 8 轮。若未来改"条目=轴/轮组"，必须另立 rule_version 并重测全部约束。
- `xr`：0=车头、1=车尾，接受后夹到 `[0.03, 0.97]`（:455）；同位置重叠不禁止。
- `rear_count` = `xr > 0.5` 的条目数（:482-487），不是"两条后轴"。
- 半径 `r ∈ [12, 30] px`（:34-35）；关卡另设 `max_r` 上限。
- 预算（仅 L4）：`Σπr² ≤ 4300 px²`（:68, :443-453）。
- **驱动轮 = 数组最后两个条目**（按添加顺序，`drive0 = n-2`，:736），不一定是车尾；只有其中接地者（`pc > 0`）参与，总驱动 `±850 / 420 px/s²` **分摊**给接地驱动轮（:746），不随接地轮数翻倍。删轮/重加会改变驱动轮——3D 兼容模式必须保留此语义；稳定 wheel_id + driven 标记是独立升级，需单独对比。
- `com_offset()`（:469）只是 UI 指标（Σr²xr/Σr² − 0.5），**不写回**质量分布或刚体质心。

## 6 状态机与流程（:72）

`menu → build → drive → settle → (过关: 下一关 build / 末关: final；翻车: restore=true 重进 build)`。
仅 L1 初始解锁，成功依序解锁；`total_time` 累加已结算尝试（含翻车局）。布局快照按关卡存 `last_layout_by_level`（内存，非磁盘）；`start_level(i, restore=true)` 只读**目标关自己的**上一份布局（:389-393），首次进新关无历史不预填。`_reset_run()`（:374）现只清 `unlocked/total_time`——3D 版须区分"重置进度"与"清除实验记录"并保证语义一致。

## 7 幽灵与遥测隔离（缺口修补）

- 幽灵键：`level_id + geometry_seed(900+i*77) + rule_version(r3d-1) + build_id`。
- 旧缺口（已在本 worktree 证实）：`start_level`(:408) 与 `do_launch`(:550) 清 `ghost_pts`，驾驶绘制需 `ghost_pts ≥ 2`(:1034) → 上一局幽灵被销毁；`cur_ghost_pts/ghost_n/was_bottom`(:101-103) 新局不重置 → 串局。
- 3D 规则：上一局与当前局独立缓冲；采样改按时间对齐（旧每 6 物理帧取点 :777-779 不作回放基准）；幽灵无碰撞、不写回车辆；暂停/重试/换车不串轨迹。
- 遥测六指标：用时、最大俯仰、全轮离地累计、托底事件、任一轮接地帧率、结算原因；3D 另加最大横滚、偏航/侧滑、偏离赛道、辅助启用时间（先定义后比较，不与旧指标混算）。
