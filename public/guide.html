📖 TapTap2026 操作指南

照着做，做完一项勾一项（勾选状态自动保存在本机浏览器里）· 由 ZCode 生成于 2026-10-02

① 把游戏传上 itch.io 现在就能做 · 1 分钟

打开 sxguan.itch.io/taptap2026 → 点顶部 Edit project
在 Uploads 区点 Upload files，选择 D:\GIT\taptap2026\dist-itch\v0.0.2.zip（23MB，Godot 4.7 构建）
上传完成后点这个 zip，勾选 "This file will be played in the browser"，Viewport 填 960 × 540
拉到底 Save & view page → 输密码 taptap 确认能玩

以后更新版本：跑 tools\export-web.ps1 出新包 → tools\package-itch.ps1 打 zip → 重复上传。想全自动看 ②。

② 配置全自动发布（GitHub CI）一次配置 · 永久生效

登录 github.com/new → 仓库名 taptap2026 → 选 Public（免费 Pages 的要求）→ Create repository
本机 Git Bash 里执行（把「你的用户名」换掉）：cd /d/GIT/taptap2026 git config user.email "你的GitHub邮箱" git remote add origin https://github.com/你的用户名/taptap2026.git git push -u origin mainpush 卡住就多重试几次（国内对 github.com 时好时坏）
仓库网页 → Settings → Secrets and variables → Actions：
Variables 标签 → New repository variable：名字 ITCH_TARGET，值 sxguan/taptap2026
Secrets 标签 → New repository secret：名字 ITCH_API_KEY，值 = 你的 itch API Key（就是你粘在 /key 页面那串）
仓库网页 → Settings → Pages → Build and deployment → Source 选 GitHub Actions
验证：仓库 Actions 标签页看「导出并发布」跑绿 → itch 页面出现新构建 → https://你的用户名.github.io/taptap2026/ 能打开

为什么要绕 GitHub：你的网络把 api.itch.io 的 TCP 直连掐断了（本机 butler 推不上），GitHub 的服务器没这个问题。配好之后 git push 一次 = 自动构建 + 更新 itch + 更新 Pages。

③ 接入 Miro 设计板 你正在注册 · 5 分钟

完成 Miro 注册登录，新建一个 board，把游戏设计/脑图/参考图放进去
Board 右上 Share → 链接权限改为 Anyone with the link → Viewer（评论者更好） → 复制链接发给 ZCode
（可选，想让 ZCode 深度读写 board 时才需要）：miro.com 右上头像 → Settings → Your Apps → Create new app → 创建后在 App 页面复制 Access Token
打开 localhost:8787/key 粘贴 Token 保存 → 跟 ZCode 说一声

只给公开链接也行，ZCode 就能看内容；Token 的用处是让 ZCode 能直接在 board 上读便签、建卡片。

④ 本机 butler 推送（可选，需要代理）

现状：本机直连 api.itch.io 被网络掐断（TCP 100% 重置），butler 用不了；浏览器能开是因为走了 QUIC/UDP
装好代理（Clash / v2rayN 等）后，在项目目录执行：set HTTPS_PROXY=http://127.0.0.1:7890 tools\push-itch.ps1 -Version v0.0.2（端口按你的代理软件改）

⑤ 日常开发循环（背下来）

改游戏：Godot 打开 game\project.godot（本机已装 Godot 4.7.2：tools\godot\）
自测：双击 启动Review站点.bat → localhost:8787 玩一圈、收反馈（反馈存在 data/db.json）
发布新版本：tools\export-web.ps1 -Version v0.0.3 -Notes "这次改了啥"
上线：git add -A git commit -m "v0.0.3 说明" git push→ CI 自动更新 itch + Pages，朋友刷新就能玩到

⑥ 踩坑速查

GitHub 下载慢/断：浏览器或 curl 前面加 https://gh-proxy.com/ 前缀；git push 失败就重试
游戏里中文变方框：别删 game/fonts/NotoSansSC.ttf（Godot 网页导出默认不带中文字体，项目已内置）
导出报错：多半是换/升 Godot 后没装模板（编辑器 Editor → Manage Export Templates）；本机模板已装好在 %APPDATA%\Godot\export_templates\4.7.2.stable
换了 Godot 版本：同步改 .github/workflows/deploy.yml 里的两个下载 URL
Key 安全：/key 页面只存本机 data/secrets.json（gitignore，不上传不进 git）；itch key 弄丢了去 itch Settings → API Keys 重新生成
