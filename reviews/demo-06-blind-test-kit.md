# demo-06「词条涂鸦创造」真人盲测执行手册（v1）

- 依据：ChatGPT 专属对话历轮裁定汇编（reviews/chatgpt-demo-06-tel-full.md、chatgpt-demo-06-v6-full.md）
- 适用版本：demo-06-v12（Playtest Baseline：L1-L6，4词条×3形状固定尺寸）
- 在线地址：GitHub Pages https://tonyguan530.github.io/taptap2026/builds/demo-06-v12/ （itch 恢复后同版本）
- 组织者：1 人（也承担录屏与数据封口）

## 一、参与者与规模
- 5~8 名**未参与开发**的玩家，逐人单独进行。
- 每人 10~15 分钟（含开场说明）；只测 **L3 为主 Gate**（L4/L6 为迁移观察，通关 L3 后自然到达，不引导）。

## 二、开场白（逐字念，不要自由发挥）
> 这是一个小物理谜题游戏。你有墨水，点击画面就能把物品画出来，画出来的东西有物理。右上角先选形状再选词条，点画面放置。目标是让小恐龙到 GOAL 旗那里。开始吧。

**四词条基础定义（每条一句，玩家问到才说）：**
- Heavy：很重，掉下去会砸碎脆的东西。
- Float：悬浮在原地，可以当平台踩。
- Fire：会点燃易燃的东西。
- Sticky：碰到东西就会粘住固定。

**绝对不要说**：「这一关有三种解法」「你可以搭桥」「推箱子也行」或任何方向性提示。

## 三、组织者操作流程（每人与每位之间）
1. 开始录屏（全程，含玩家说出的话）。
2. 玩家游玩；组织者**不打断、不提示**；卡住超 3 分钟只说「你可以随时换一种思路或按 R 回到起点」。
3. 玩家通关或放弃后：点击游戏右下角「📦数据」→ 点「结束本次测试(未通关)」（通关会自动封口）→ JSON 已自动复制 → 粘贴保存到本地文件（按 P01.json、P02.json…命名）。
4. 每人结束在记录表写一行摘要（见下）。
5. 下一位（游戏页面刷新一次以清空上一位残留状态）。

## 四、观察记录表（每人一行，判读核心）
```
P01 | 通关?Y | 首解=Float桥 | 用时182s | 组合尝试6 | 有意义实验3 | 用环境物Y | 新解N | intentional
```
字段说明：
- **首解**：第一次成功通关用的路线（描述即可，如「浮板搭桥」「推箱子垫脚」）。
- **组合尝试数**：放置过多少个不同的 形状×词条 组合（telemetry 的 place 事件可数）。
- **有意义实验**：排除断线重连/纯手滑后，有明确意图的尝试次数。
- **用环境物**：是否推动了场景里的箱子/球/木板。
- **新解 D**：出现了开发组没预设的解法（最重要的一列！）。
- **intentional / accidental / unclear**：解法是有意设计还是偶然发现（看录屏判断；accidental→理解因果→后续复用是最强信号）。

## 五、数据回收
- 每人一个 JSON（📦复制）+ 一段录屏 + 一行摘要。
- JSON 按会话号（sid）自动分段；四个回放问题：首次试 Heavy 的时间点 / Sticky 是否被尝试 / 组合尝试总数 / 成功前有意义实验次数。
- **L3 与 L4/L6 分开统计**：L3 = 自发发现/解法多样性/涌现链；L4/L6 = 规则迁移（L3 用 A 路线的人 L4/L6 是否换路线）。

## 六、数据齐后
- 把「每人一行摘要 + 典型行为描述 + 全部 JSON」交给 ChatGPT 专属对话做 Gate 判定。
- 判定问题：玩家是否主动尝试超过一种系统关系？解法是否分叉？是否出现 D 解？
