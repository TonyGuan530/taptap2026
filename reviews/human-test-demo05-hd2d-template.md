# demo-05 HD-2D 真人空间学习测试模板（督导 KEEP Gate 执行件）

- 依据：reviews/chatgpt-demo05-hd2d-c3-full.md（2026-10-05 裁决）
- 测试版：demo-05-hd2d-v6 → https://tonyguan530.github.io/taptap2026/builds/demo-05-hd2d-v6/index.html
- 规模：2–3 名首次玩家 × 至少 2 个夜晚 × 至少 1 次死亡后重开（督导原话：不需要五个人）
- 目标：验证「吃过一次空间上的亏以后，玩家下一次会不会主动改变营地位置、路线或投资，并能说明原因」

## 测试纪律（勿违反）

1. **不解释**预报语义、灰潮/泥流机制、营地区位策略——只给操作说明（WASD 移动 · E 交互 · Q 吃 · R 喝 · B 建造 1/2/3 选型 E 放置 · Enter 重开）。
2. 不优化 HUD 提示强度（督导明确禁止：红色风险区预览/"建议往西建"/安全线/建造自动警告）。
3. 不统计胜率——通过条件不是胜率。
4. 玩家原话逐字记录（归因与解释是核心数据）。

## 每位玩家记录单

| 字段 | 记录 |
|---|---|
| 玩家编号 / 日期 | |
| 第 1 夜 shelter_build_x | （东侧为正、西侧为负；telemetry 自动记录，人工复核） |
| 第 1 夜是否遭灰潮影响 | 窝被覆盖无法睡 / 灰区受伤 / 未受影响 |
| 第 1 夜是否被泥流挡路 | 是（绕行？放弃？）/ 否 |
| 重开/第 2 夜 shelter_build_x | |
| shelter_build_x 是否改变 | 西移 / 东移 / 不变 |
| 白天采集路线是否改变 | 因灰潮（东） / 因泥流（北谷） / 因预报 / 未变 |
| 是否采信萨满预报 | 提前调整了什么（建窝位置/采集方向/设施投资） |
| 口头解释（逐字） | 「为什么这次这样建/这样走？」 |
| 归因（督导四指标延续） | 失败/惨状：自己决策 / 随机事件整我 |
| 预报错那晚的反应 | 发现预报错了？之后还信吗？ |

## 通过判定（督导口径）

- **KEEP 条件**：2–3 人中 ≥2 人**在无提示情况下**，根据上一夜世界反馈主动改变空间策略（shelter_build_x 西移 / 路线改道），且口头解释指向「上次灰/泥流过来了」而非「随便试试」。
- 附加正向信号：预报错的那晚之后，玩家对预报从盲信转为条件采信（更高的涌现证据，非必需）。

## 数据通道

- 自动：`user://hd2d_telemetry.jsonl`（逐日 JSONL：shelter_build_x 数组 + 灰暴露秒数；端到端验收 4/4 PASS）
- 人工：本模板记录单 + 玩家原话
- 汇报：数据到达当轮优先消化，按督导五指标+空间学习链做 KEEP 判定汇报发督导对话
