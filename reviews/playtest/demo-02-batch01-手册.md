## 开场白（照读）

> 这是一个第一人称物理解谜 demo，一共 5 关。按 1/2/3 可以给球换「词条」，物理行为会跟着变。目标：把球送进金色的 GOAL 门框。WASD 走，鼠标看，卡住了按 R 重置球。开始吧，你想怎么玩都行。

**不说**：路线、参考解法、阈值数字、哪个词条好使、L4 有两条路线、L5 会自动通关。

## 观察守则（只记录，不提问，不提示）

- 玩家卡住 >30 秒开始挣扎时才允许第一次提示：「试试按 R 重置」；仍卡住记录一次「需提示」
- 玩家通关后**不说话**，观察是否主动说「下一关」/继续玩（replay_voluntarily）
- 不问「觉得好玩吗」；只在全部结束后问一句「你刚才是怎么想到这么过的？」并原话记录
- **L5 特别守则**：玩家看到皮球自动弹跳通关时，记下反应（惊喜/困惑/无意识/以为是自己操作的）；不要解释
- **L4 特别守则**：无论玩家走哪条路线都不要点评「还有另一种走法」

## 每人一张记录表

通关瞬间屏幕下方会打印遥测行（格式 `TEL3D|L3|9.9s|idle=false|皮球@0.0s[field]→羽毛@1.0s[field]|resets=0|spring=true`），整行抄录到 tel_line，其余字段据此+目测填写：

| 字段 | 记录 |
| --- | --- |
| tester_id | P01…P05 |
| tel_line（每关一行） | 抄遥测行原文 |
| first_tag_per_level | 每关首次尝试的词条（L1…L5 各一个） |
| switch_chain | 抄遥测行切换链（如 羽毛@0.0s→石头@1.1s） |
| fail_reasons | 每次失败一句话（坠谷/撞墙/板没碎/超时找不到…） |
| clear_time | 抄遥测行秒数（L1…L5 各一个） |
| resets | 抄遥测行 resets=N + 目测手动 R 次数 |
| L4_solution_family | 羽毛飘台 / 皮球弹板抛射 / New（描述）/ Failed |
| L4_unplanned_route | 是否出现两条预设路线之外的合法走法（描述，哪怕只成功一半） |
| L5_reaction | 惊喜 / 困惑 / 无意识 / 以为是自己操作的（原话） |
| **eureka_moment** | **观察员只记一次：玩家首次把旧机制用在新用途的时刻**（原话/动作描述） |
| eureka_verbal | 当时是否出现「还能这样？」「卧槽」类言行（是/否+原话） |

**Eureka 判定口径（ChatGPT 2026-10-05 专属线定义，照此执行）：**

> eureka = true：玩家首次**主动**把已在前关学到的 mechanic / 物性关系，用于当前关卡中的**新用途、非直接教学用途或非显式提示用途**，并出现可观察证据（行为或自发口头反应，至少一个成立）。

三个子字段（不再扩展更多观察项）：
- `eureka_source`：来自哪个已学 mechanic（bounce / feather_drift / heavy_impact）
- `eureka_trigger`：behavior 或 verbal
- `eureka_note`：一句话记录实际发生了什么（例：「L4 先用皮球弹板改变抛射角，未按预设羽毛路线走」）

**不计入 Eureka**：第一次知道某按钮能按；照提示执行标准解；随机误撞后通关但玩家没有表现出理解；L5 零输入自动完成本身（只有玩家观察到自动链后**主动据此做新实验**才算）。Eureka 是辅助证据，不是第四个硬门槛。
| unexpected_behavior | 一句话：玩家做过的最意外尝试（哪怕失败） |
| replay_voluntarily | 通关后是否主动再玩（强信号） |

## Batch 判定（ChatGPT 2026-10-05 定死，数据回收后交回流水线做 Gate 报告）

- **升 KEEP**：3-5 人中 L4 真实出现 ≥2 个 solution family，且 ≥1 人产出未预设合法序列；且 ≥2 人在无解释下把前关物理关系迁移到后关
- **继续 ITERATE**：都能通关但严格复现预设路线
- **危险信号**：玩家主要靠试遍 1/2/3 词条而非据运动结果形成物理假设（=认知层面仍是「钥匙试锁」）
- **统计口径**：L5 与 L2-L4 分开统计——L5 通关率不能证明 puzzle 成立（L5=toy/free-experiment 定位）
- Eureka 字段是本次新增的唯一观察项（不膨胀游戏内 telemetry）
